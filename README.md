# Barbershop Showcase

Универсальный одностраничный frontend-концепт сайта барбершопа без привязки к конкретному бренду, городу или человеку. Страница построена как редакционная scroll-story: прелоудер со skeleton-состоянием, кинематографичный hero, манифест, шесть услуг, горизонтальная сцена команды, раскрывающийся lookbook, журнал, атмосферная глава и подготовленный блок онлайн-записи.

Сейчас это демонстрационный интерфейс без backend, CMS, базы данных и booking API. Все тексты написаны на русском, реальные имена, цены, адреса, телефоны и внешние ссылки намеренно отсутствуют.

## Требования

- Node.js `>=20.19.0`;
- npm;
- современный браузер с поддержкой App Router, CSS `clip-path` и `position: sticky`.

WebGL не используется. Шрифт Manrope загружается локально. Для `prefers-reduced-motion` предусмотрена статичная композиция без pinned-анимаций, магнитного движения и pointer-зависимых переходов.

## Быстрый запуск

Из корня проекта:

```bash
npm install
npm run dev
```

После запуска открыть [http://localhost:3000](http://localhost:3000). Ожидаемый результат — нейтральная главная страница барбершопа с оранжевым акцентом и пустым состоянием онлайн-записи.

## Рабочие команды

```bash
npm run dev                         # локальная разработка (Turbopack)
npm run lint                        # ESLint
npx next typegen                    # типы маршрутов Next.js
npx tsc --noEmit                    # строгая проверка TypeScript
npm run build                       # production build в Webpack-режиме
npm run start                       # запуск готового production build
```

Отдельных scripts для тестов и format-check в проекте нет. `next build` не заменяет отдельный запуск ESLint.

## Архитектура и контент

[`src/components/home-page.tsx`](src/components/home-page.tsx) остаётся Server Component и собирает страницу из небольших интерактивных client islands. GSAP подключён только к сценам, где нужен motion.

Единственная точка подключения проектных данных — [`src/data/content.ts`](src/data/content.ts):

- `siteSettings.identity.name` — название; `null` оставляет нейтральный вариант;
- `siteSettings.identity.logoSrc` — путь к SVG или другому изображению логотипа;
- `siteSettings.bookingUrl` — общая внешняя ссылка записи; `null` включает пустое состояние;
- `siteSettings.socialLink` — необязательная ссылка на публикации;
- `branches` — филиалы, их адреса, необязательные телефоны и отдельные ссылки записи;
- `services`, `team`, `lookbook` и `articles` — редактируемые коллекции страницы.

Компонент [`src/components/site-brand.tsx`](src/components/site-brand.tsx) выводит идентичность одинаково в шапке, прелоудере и футере. Если у филиалов появятся данные, блок адресов и стилизованная карта подключатся автоматически. Пока массив `branches` пуст, карта не рендерится, а форма записи показывает доступное disabled-состояние без фиктивных контактов.

Визуальный акцент задан токеном `--color-accent: #f05a28` в [`src/app/globals.css`](src/app/globals.css). Фавикон, нейтральный знак и секционные SVG-курсоры используют тот же оранжевый цвет.

Временные изображения находятся в [`public/images`](public/images). Файлы `team-editorial-01.webp`–`team-editorial-03.webp` — сгенерированные концепт-портреты, а не фотографии сотрудников.

## Структура

```text
src/app/             App Router, metadata и глобальные стили
src/components/      серверная композиция и интерактивные client islands
src/data/            типизированный контент и настройки проекта
public/brand/        нейтральный SVG-знак, заменяемый через content.ts
public/cursors/      секционные SVG-курсоры
public/fonts/        локальные WOFF2 subsets с кириллицей
public/images/       временные WebP-изображения концепта
docs/                актуальный проектный бриф
```

Корневой рабочий контракт находится в [`AGENTS.md`](AGENTS.md). Корпоративные инженерные правила берутся из canonical `hb-development-standarts`.

## Проверка

Перед передачей изменений выполнить:

```bash
npm run lint
npx next typegen
npx tsc --noEmit
npm run build
```

В браузере проверить минимум:

- 390×844, 768×1024 и 1440×900 без горизонтального overflow;
- hero CTA и постоянную mobile-запись;
- мобильное меню: focus trap, `Escape`, возврат фокуса и скрытие фонового контента;
- desktop sticky service-preview с pointer и клавиатуры, inline media на touch;
- horizontal team track, lookbook reveal и переходы по якорям;
- пустое состояние записи без адресов, телефонов и внешних ссылок;
- `prefers-reduced-motion` и отсутствие ошибок или предупреждений приложения в console.

## Границы концепта

- Реальный логотип, контакты, филиалы и ссылки добавляются только после подтверждения данных.
- Атмосферная глава использует poster fallback; видео подключается после подготовки материалов и проверки прав.
- Имена, портреты сотрудников и цены намеренно не выдуманы.
- Материалы журнала показаны как концепт-превью, а не опубликованные статьи.
- Production-конфигурация, аналитика и интеграция с системой записи не входят в текущий scope.

# project-barbershop
Иммерсивный сайт-концепт барбершопа на Next.js 16, React 19 и TypeScript. Редакционная scroll-story с кинематографичной типографикой, GSAP-анимациями, адаптивным интерфейсом и доступностью — с фокусом на визуальную выразительность, минимальный клиентский JavaScript с максимальную производительность.
